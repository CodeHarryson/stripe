# DSA maintenance set

Use only 15–20% of total prep time here. Solve in Python and explain the pattern, invariant, complexity, and edge cases. Complete the Stripe-specific stateful set in `STRIPE_STATEFUL_SET.md` before adding unrelated problems.

- LeetCode 49 — Group Anagrams (normalization/grouping)
- LeetCode 3 — Longest Substring Without Repeating Characters (sliding window)
- LeetCode 347 — Top K Frequent Elements (counting and deterministic output discussion)
- LeetCode 238 — Product of Array Except Self (prefix/suffix semantics)

## After every problem

1. What assumption did you clarify?
2. What invariant makes the algorithm correct?
3. Which edge case was easiest to miss?
4. Could you implement it again tomorrow without recognizing a memorized template?
