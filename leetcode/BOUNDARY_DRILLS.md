# Boundary drills

## Binary search

Before coding, complete: “At every iteration, the answer is contained in ______.” Define whether `hi` is inclusive or exclusive. Test empty input, one item, absent target, first position, and last position.

## Prefix sums

Write the sentence “`prefix[i]` represents ______.” Derive the range formula from that sentence. Test a range beginning at zero, one element, and the full array.

## Sorting and ties

For every multi-key sort, write the key tuple and whether each component is ascending or descending. Test equal primary keys.
