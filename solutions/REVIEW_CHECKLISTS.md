# Post-attempt solution review

This repository intentionally avoids copy-paste full solutions. After your attempt, compare against these properties.

## A strong implementation

- parses once into a stable, explicit representation;
- isolates validation/eligibility from aggregation and formatting;
- produces deterministic output;
- preserves prior tests when a requirement changes;
- handles empty input, duplicates, ties, and boundary values intentionally;
- uses idiomatic Python without unnecessary abstraction;
- states time and space complexity accurately;
- can be explained line by line by the candidate.

If your solution misses a property, revise it and rerun tests. Mark “Independently solved” only if you did not need these notes; mark “Mastered” only after a clean later re-solve.
